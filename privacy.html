一、适用范围与您的选择

本政策说明当前 Android 单机游戏中的实际数据处理。本游戏没有玩家账号、手机号注册、实名认证、充值支付、聊天、云存档或服务端排行榜。您可以不同意并继续离线游玩。阅读全文、点击返回、关闭应用或继续游玩都不视为同意。广告等非必要处理需要适当告知和依法必要的独立同意，当前同意不预先授权未来新增的 SDK。

二、本地保存的内容与用途

1. 游戏进度：关卡解锁、最高星级和分数、用时、挑战与奖励结算记录，用于恢复进度和防止重复结算。
2. 收集内容：小鱼干收支账本、动物解锁、装扮拥有及穿戴状态、吉祥物选择，用于离线收集和展示。
3. 声音设置：音乐与音效音量、静音及已选音效设置，用于记住偏好。
4. 隐私选择：同意或不同意、政策版本、告知修订号、选择时间，以及将来另行选择的广告同意范围，用于尊重选择和避免重复询问。它们不包含姓名、联系方式或设备标识符。
5. 广告奖励接口预留本地奖励凭据摘要、结算随机编号和日期，以便将来防止重复发奖；当前没有正式广告 SDK，因此不会从真实广告平台取得奖励凭据。

这些文件保存在 Godot 的 user:// 应用私有目录。当前业务代码不向游戏运营者或第三方上传这些文件，不读取通讯录、相册、定位、麦克风、相机、剪贴板或设备广告标识符，也不申请外部存储读写权限。屏幕尺寸、安全区域和触控事件仅用于本机布局和操作；系统时间和本机随机数用于计时、随机棋盘与奖励去重，不用于跟踪身份。

三、网络、权限与第三方服务

当前导出预设关闭 INTERNET、网络状态、Wi-Fi 状态和外部存储权限；业务脚本没有 HTTP 请求或联网服务。最终安装包仍应核对合并后的 AndroidManifest 和设备行为，原生插件变动必须重新审查。

本版本未接入正式广告、TapSDK、登录、统计、推送、支付或云存档 SDK。Godot 是本地游戏运行引擎，不是广告或用户分析服务。发布到 TapTap 不表示本游戏已经集成 TapSDK。

激励广告目前仅预留接口，没有真实广告请求，不会因点击广告入口而获得虚假奖励。广告暂不可用时，可返回、使用小鱼干购买装扮或继续正常游玩。

本游戏不使用浏览器 Cookies、个性化推荐或跨应用跟踪。TapTap 商店客户端自身处理的信息由其自身政策说明，不等于本游戏内已接入对应 SDK。

四、广告同意与撤回

若未来启用激励广告，我们会先更新实际 SDK 的名称、提供方、版本、目的、个人信息类型、权限、保存方式及官方政策链接，另行展示并取得依法必要的同意，然后才允许延迟初始化和用户主动请求广告。缺少清单或同意时不初始化、不预加载、不检查 SDK 广告库存、不请求广告。不同意、撤回或政策相关范围变化后，停止新的广告调用。拒绝广告不影响离线关卡、基础奖励、小鱼干购买和已拥有装扮。

在设置 → 隐私政策中可重新查看、重新选择或撤回同意。撤回不会删除关卡和装扮。撤回前已合法处理的信息不因撤回自动失去原有合法基础；已确认但尚未写入的本地奖励仍可重试保存。若以后使用第三方服务，涉及其已有数据的权利请求方式将随真实 SDK 清单更新。

五、保存期限、安全与删除

进度和偏好在您使用本应用期间留在本机，直到您通过 Android 设置 → 应用 → 爪爪连连看 → 存储 → 清除数据，或卸载应用并删除应用数据。本版本关闭 Android 应用数据自动备份，没有云端恢复功能；清除数据会永久丢失进度、小鱼干和装扮，请谨慎操作。仅撤回同意不等于删除这些离线记录。

本地存档采用临时文件和备份保护以降低中断写入风险；隐私选择单独保存，不修改原有进度。文件不是端到端加密档案，不能承诺抵御已被破解或由其他人控制的设备访问。本游戏没有运营者远程数据库，因此无法替您远程恢复或修改本机存档，也没有由本游戏发起的数据跨境传输。

Godot 运行时可能在本机写入错误日志；游戏没有自动上传日志的功能。开发测试模式可在隔离目录记录关卡编号、随机种子、用时和操作统计，仅供本机调试；正式玩家模式不启用该开发测试采集。您主动向开发者发送日志或联系信息时，请仅提供解决问题必要的内容，其处理方式需由运营者通过有效联系渠道说明。

六、您的权利与联系

您可在关卡页查看成绩，在图鉴和快乐橱窗查看及修改装扮，在设置中修改声音偏好和隐私选择；可以通过 Android 清除应用数据删除本机全部记录。当前没有账号，因此不存在账号注销入口。若对本政策、访问、更正、删除或其他个人信息权利有疑问，可使用本页所列隐私联系渠道；运营者将在适用法律要求的期限内处理。运营者须在发布前补齐可用的联系渠道。

七、未成年人保护

未成年人请在监护人指导下阅读和使用。涉及不满十四周岁未成年人个人信息的处理，应按适用要求取得监护人同意并采取相应保护措施。当前没有线上身份或年龄核验流程，也未接入广告 SDK。本提示不能代替未来儿童个人信息保护规则、监护人同意机制或其他依法应履行的义务；启用相关服务前须重新评估并完善。

八、政策更新

可在设置随时查看当前版本。文字修正可更新文档版本；处理目的、方式、信息种类、接收方等重要内容变化时，会更新告知修订号并再次提示；依法应重新取得同意的处理在获得新同意前保持关闭。新增或变更 SDK 清单还会使旧广告授权失效。旧版本由运营者在项目版本归档中保留。
